# QuantChallenge 2025

This is our complete repository submission for QuantChallenge2025 (TEAM_2485).

**Team Size:** 4

**Result:** Top 8% out of 1400+ teams

## Overview
Time-series prediction challenge using an 80,000-row financial dataset 
to optimise PnL in a simulated live trading environment.

## Approach
- Compared multiple ML models: Lasso, Linear Regression, 
  Gradient Boosting, and RandomForest
- Used time-series cross-validation to prevent data leakage
- Selected the most robust model based on out-of-sample performance
- Deployed final model to generate live trading predictions

## Tech Stack
Python: pandas, scikit-learn, matplotlib
